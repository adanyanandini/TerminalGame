# TerminalGame
## Terminal-Based Tic-Tac-Toe Game Using Python

The Terminal-Based Tic-Tac-Toe Game is a text-based board game developed using Python 3. The application allows users to play Tic-Tac-Toe either against a computer or against another player through a terminal interface.

The system provides a clean menu-driven interface with Player vs Computer and Player vs Player modes. It also maintains a scoreboard, provides score reset functionality, validates user inputs, detects winning combinations, and identifies draw situations.

The computer opponent uses a simple decision-making algorithm to win when possible, block the player's winning move, occupy the center, select corners, and finally select an available position.

The complete application is implemented in a single Python source file and does not require graphics or external libraries.
